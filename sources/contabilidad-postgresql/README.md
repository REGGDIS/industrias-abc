# Sistema Operacional de Contabilidad — PostgreSQL

Carpeta destinada al desarrollo del sistema operacional de Contabilidad de Industrias ABC.

## Alcance inicial

- Cuentas contables y su estructura jerárquica.
- Centros de costo asociados a las áreas de la empresa.
- Movimientos contables con Debe, Haber, documentos, moneda y tipo de cambio.
- Datos de prueba y scripts SQL del dominio.

## Referencias

El diseño debe respetar el Trabajo Práctico Integrador de Business Intelligence, el IDF v0.2 y el Modelo Conceptual v0.1 aprobados para Contabilidad. Los datos comunes de áreas y centros de costo se homologarán posteriormente con el Universo Empresarial Master v0.2, sin exigir claves físicas compartidas entre fuentes.
